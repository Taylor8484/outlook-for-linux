# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

Only the latest release receives security updates. Please upgrade to the latest
version to get fixes.

## Reporting a Vulnerability

If you discover a security vulnerability in Outlook for Linux, please report it
responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Use [GitHub's private vulnerability reporting](https://github.com/Taylor8484/outlook-for-linux/security/advisories/new)
   on Taylor8484/outlook-for-linux to submit details confidentially.
3. Include a description of the vulnerability, steps to reproduce, and the
   potential impact.
4. You can expect an initial response within 7 days.
5. We will work with you to understand the issue and agree on a fix and
   disclosure timeline.

Vulnerabilities in the Microsoft Outlook web app itself should be reported to
Microsoft through the [Microsoft Security Response Center](https://msrc.microsoft.com/).
