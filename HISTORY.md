# History

Outlook for Linux is built from
[teams-for-linux](https://github.com/IsmaelMartinez/teams-for-linux), the
unofficial Microsoft Teams client for Linux maintained by Ismael Martinez.

- **2023:** [mahmoudbahaa](https://github.com/mahmoudbahaa/outlook-for-linux)
  forked teams-for-linux and adapted it to wrap the Outlook web app, creating
  the original outlook-for-linux.
- **2026:** [Taylor8484](https://github.com/Taylor8484/outlook-for-linux)
  re-forked outlook-for-linux on top of teams-for-linux 2.21.0 (Electron 43),
  removed the Teams-only features, and restarted versioning at 2.0.0.

Thanks to everyone who contributed to teams-for-linux and to the original
outlook-for-linux fork. See [`CHANGELOG.md`](CHANGELOG.md) for release notes.
